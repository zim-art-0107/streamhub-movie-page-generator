# StreamHub Movie Page Generator

A JavaScript-based tool built to support the StreamHubOnline content workflow by generating movie-page content and SEO-focused information with the help of AI integrations.

> Portfolio project showcasing JavaScript development, AI-assisted content generation, and media workflow automation.

## Overview

The Movie Page Generator was developed to streamline parts of the movie-page creation process for StreamHubOnline. It combines AI-assisted content generation with media-related functionality to reduce repetitive manual work.

## Features

- **AI-powered content generation** — Generate movie-related and SEO-focused content using AI integrations.
- **Media workflow support** — Support featured-image handling and media uploads.
- **SEO content preparation** — Help structure content for movie pages.
- **Workflow automation** — Reduce repetitive steps in the content publishing process.
- **Modular JavaScript code** — Separate functionality across JavaScript modules and styling files.

## Technologies

- JavaScript
- AI API integration
- WordPress media integration
- CSS
